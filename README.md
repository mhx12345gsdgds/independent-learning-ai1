# Independent Learning AI · 自主学习网格世界

**研究问题**：当教师退出后，学生能否用自己积累的经验预测动作结果，并在新地图上规划路线？课程指导能否减少达到同一水平所需的环境交互？

这个原型从随机初始化的 PyTorch 网络开始。学生在模拟器中试走，保存每次观察、动作和实际结果，然后学习一步动力学。评估时冻结权重，使用预测生成可达图，在图上搜索路线。保存的学生可以独立加载使用。

## 运行实验

在解压后的项目目录运行以下命令。机器上已有可用 PyTorch 和 NumPy 时，可跳过安装。使用 Python 3.10 或更高版本，默认在 CPU 上运行。

```powershell
python -m pip install -r requirements.txt
python -m ila run --out runs/first
```

默认使用 3 个训练种子、每组每种子 18 张训练图及 1,440 次环境交互。每个检查点在两类地图各测试 24 张。输出目录需要是新目录，以保留之前的测量结果。

用随项目提供的权重在一张新地图上查看实际轨迹。终端会显示起点、终点、走过的位置，以及每一步的预测和观察结果。

```powershell
python -m ila demo --weights example/weights.pt --split shifted --map-id 31 --trace trace.csv
```

把 `example/weights.pt` 换成自己的 `runs/first/seed-11/guided/weights.pt`，就可以回放刚训练的学生。使用大于等于 24 的地图编号可以生成默认评估之外的地图。

## 实验怎么控制变量

| 组别 | 训练时如何选动作 | 评估时如何选动作 |
| --- | --- | --- |
| `random_policy` | 无训练 | 均匀随机 |
| `random` | 均匀随机 | 世界模型规划 |
| `autonomous` | 随机热身后，优先尝试当前地图中在该位置较少尝试的动作 | 世界模型规划 |
| `guided` | 同样热身。训练前半程按递减概率使用教师指定的探索策略，其余时间使用自主组策略 | 世界模型规划 |

三个学生组在同一种子下共享网络初始权重、地图顺序、交互次数和优化步数。采集阶段到达终点后继续探索，以保持每图预算一致。测试地图由独立种子域生成，同一张地图会配对用于各组和各检查点。评估过程不更新权重，也不会把测试经验加入回放。来到模型预测图中没有通往目标路线的位置时，各学生组使用同一随机补救规则。

- **观测**：地图、当前位置和目标坐标可见。地图格子是离散编号。学生用局部 3×3 编号和动作编号预测一步位移，使用真实交互结果自动生成训练标签。
- **世界模型**：小型多层感知机预测原地停留或四种位移的概率。地图上的每个位置和动作都独立预测，规划器仅用预测产生的边搜索。模拟器的真实最短路径仅供地图生成和评分。
- **迁移**：`heldout` 保持训练地图的尺寸和障碍生成概率。 `shifted` 从 8×8、0.18 改为 11×11、0.28。两种地图共用相同的物理规则。
- **能力范围**：本实验测量离散观测上的规律学习、同一动力学下的地图迁移、探索与经验回放。可见地图、明确目标、离散动作和有限位移类别是人为给定的实验条件。像素感知、跨任务域迁移和语言理解留在本实验范围之外。

环境是项目内的四方向网格模拟器。MiniGrid 可作为扩展环境参考。[DI-engine 的 MiniGrid 文档](https://opendilab.github.io/DI-engine/13_envs/minigrid.html)

## 接入本地大模型教师

默认教师是写好的课程，用来离线跑通对照。已有本地 Ollama 服务和已下载的聊天模型时，可以在 PowerShell 中运行：

```powershell
ollama list
$teacherModel = Read-Host "输入 ollama list 中的本地模型名"
python -m ila run --ollama-model $teacherModel --out runs/llm
```

课程通过本机 `127.0.0.1:11434` 请求一次。教师提供自然语言学习目标和两个阶段的探索策略。学习目标用于记录和审阅，策略会真正影响采样。允许的策略有均匀随机、优先尝试少见的观测动作组合和优先尝试世界模型预测熵较高的动作。教师看不到训练或测试地图。大模型课程和来源会随结果一起保存，可以复用同一份课程做重复实验。[Ollama 结构化输出文档](https://docs.ollama.com/capabilities/structured-outputs)

```powershell
python -m ila run --curriculum runs/llm/config.json --out runs/llm-repeat
```

## 怎么读结果

| 文件 | 内容 |
| --- | --- |
| `config.json` | 种子、样本预算、环境设置、教师来源及课程 |
| `summary.csv` | 每组各交互预算下的平均表现和跨训练种子成功率标准差 |
| `episodes.csv` | 每种子、每地图的结果，可用于按地图和种子配对 |
| `seed-*/<组别>/training.csv` | 每张训练地图的教师介入次数和探索覆盖统计 |
| `seed-*/<组别>/experience.npz` | 每一步观测、动作、位移标签、地图编号及前后坐标 |
| `seed-*/<组别>/weights.pt` | 独立运行学生所需的模型参数 |

成功率衡量步数预算内到达目标的比例。SPL 对失败记零，成功时记真实最短步数除以实际步数。下一状态准确率在起点可达的所有状态和动作上测量，先算每张地图，再在地图间平均。`blocked_recall` 和 `move_accuracy` 分别衡量实际停留和实际移动时的预测表现，便于发现模型是否一味预测停留。

用 `random` 与 `random_policy` 比较从经验学习后规划带来的变化，用 `autonomous` 与 `random` 比较探索方式，再用 `guided` 与 `autonomous` 比较课程增量。末次指标可能接近满分，课程的样本效率应看早期检查点。多种子复用同一套测试地图，因此汇总的回合数含重复地图。示例结果见 [实验记录](example/RESULTS.md)。

## 代码入口

- `ila/world.py`：地图生成与真实移动规则。
- `ila/student.py`：观测编码、经验回放、一步预测和模型规划。
- `ila/teacher.py`：脚本课程、Ollama 一次性课程和结构验证。
- `ila/experiment.py`：同预算训练、检查点测试和结果汇总。
- `ila/__main__.py`：训练和独立回放命令。
